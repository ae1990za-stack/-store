هايبر عام - نسخة محدثة

الملفات:
- index.html: الموقع كامل (HTML/CSS/JavaScript) في ملف واحد.
- manifest.json و service-worker.js: إعدادات PWA أولية.
- vercel.json: إعداد استضافة Vercel.
- .nojekyll: إعداد GitHub Pages.

التحديثات:
- لوحة إدارة المنتجات والأسعار والصور.
- حقل نسبة خصم للمنتج، وحساب السعر قبل الخصم تلقائيًا عند تركه فارغًا.
- إدارة البنرات ومكان ظهورها، بما فيها مساحة بنرات إضافية.
- إدارة الكوبونات والعروض.
- إعداد رقم التواصل مع الدعم/واتساب.
- إدارة الاشتراكات يدويًا (لا توجد مدفوعات آلية مدمجة).
- فواتير وطلبات ولوحة للعملاء.
- قسم العملاء يتضمن تنزيل بيانات العملاء JSON ونسخة احتياطية كاملة JSON.
- الإعدادات وكلمات المرور التجريبية.

التخزين:
تُحفظ البيانات في localStorage على نفس المتصفح والجهاز وعنوان الموقع. تبقى عادةً بعد إغلاق المتصفح، لكن لا يمكن ضمان عدم حذفها: قد تُحذف عند مسح بيانات الموقع/المتصفح أو تغيير المتصفح أو الجهاز. لذلك نزّل النسخة الاحتياطية من لوحة التحكم > العملاء بانتظام. هذا ليس خادم قاعدة بيانات مشتركًا، ولن تتزامن الطلبات بين أجهزة مختلفة.

الأمان:
هذه نسخة تجريبية؛ كلمات المرور داخل ملفات الواجهة ليست حماية حقيقية. لا تستخدمها لتخزين بيانات حساسة أو لاستقبال طلبات حقيقية دون خادم وقاعدة بيانات ومصادقة آمنة.

التجربة:
افتح index.html في متصفح حديث. بعض خصائص PWA والإشعارات تحتاج HTTPS عند الاستضافة. الإشعارات المحلية لا تعني إرسال إشعارات تلقائية لجميع العملاء على أجهزة مختلفة.

الاستضافة:
ارفع محتويات المجلد إلى GitHub Pages أو Vercel. لا ترفع ملفات ZIP نفسها بدل فك ضغطها.

APK:
هذا ليس ملف APK نهائيًا؛ يلزم تغليف المشروع واختباره وتوقيعه بأداة Android مناسبة قبل التوزيع أو نشر Google Play.
